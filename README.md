# Проект: Анализ и предсказание продаж видеоигр

## Описание проекта
Данный репозиторий содержит лабораторные работы по курсу машинного обучения. 
Цель проекта — построение модели машинного обучения для предсказания мировых продаж видеоигр (задача регрессии). 

В ходе **Лабораторной работы №1** был проведен разведочный анализ данных (EDA) на основе датасета *Video Game Sales & Metacritic Intelligence 1980–26* (50 000 записей). 
В рамках ЛР1 выполнены:
- Настройка структуры проекта и виртуального окружения.
- Инициализация Git-репозитория.
- Очистка данных и обработка аномалий.
- Разведочный анализ данных (построение графиков, анализ распределений и корреляций).
- Сохранение очищенного датасета для дальнейших лабораторных работ.

**Целевая переменная:** `global_sales_million` (мировые продажи в миллионах копий).

Результаты разведочного анализа данных (EDA)

В ходе анализа были сделаны следующие ключевые выводы:

1. Качество и структура данных:

    Данные успешно очищены: удалены неинформативные идентификаторы (game_id, title), которые могли привести к переобучению.

    Проведена оптимизация памяти: текстовые признаки переведены в тип category, числовые — в минимально достаточные целочисленные типы (int8, int16, int32).

    Выполнена фильтрация невалидных записей: удалены F2P-игры (с нулевой ценой), игры с нулевыми продажами и без отзывов. Потеря данных составила 7.94% (данные стали чище, но объем выборки достаточен).

    Пропусков, дубликатов и логических ошибок (вроде отрицательных продаж или оценок >100) не обнаружено.

2. Анализ целевой переменной (global_sales_million):

    Выявлена сильная правосторонняя асимметрия (skew = 7.74). Большинство игр продаются в диапазоне 5–30 млн копий, но есть редкие мега-хиты (свыше 1000 млн).

    Логарифмирование (np.log1p) приводит распределение к почти нормальному (skew = 0.17). В связи с этим на этапе моделирования (ЛР2) предпочтение будет отдано метрике MAE, которая устойчива к выбросам.

3. Влияние признаков:

    metacritic_score — высокоинформативный признак. Игры с оценкой 80+ продаются в среднем в 3–4 раза лучше.

    platform_type — мобильные игры (Mobile) имеют самую высокую медиану продаж, а консоли (Console) — огромный разброс (от инди до блокбастеров).

    genre — сильный предиктор. Жанры Platform, Shooter и Action лидируют по медиане продаж.

    publisher_tier — рынок сильно разбалансирован: игры AAA обеспечивают ~94% всех денежных поступлений.

    Мультиколлинеарность: выявлена корреляция между metacritic_score и user_score (r ≈ 0.6), а также почти идеальная корреляция (~1.0) между временем прохождения сюжета и полного прохождения.

4. Главный вывод для этапа моделирования (ЛР2):
Корреляции с целевой переменной слабые (все |r| < 0.25), а связи — нелинейные. Простые линейные модели здесь не подойдут. Оптимальный выбор — алгоритмы на основе деревьев решений (RandomForest), так как они устойчивы к асимметрии и улавливают сложные взаимодействия. Признаки platform, genre, publisher_tier и metacritic_score обязательно войдут в модель.

## Лабораторная работа №2. Проведение экспериментов по настройке модели

Скрипт запуска находится в директории `./mlflow/start_mlflow.sh`.

Чтобы запустить MLflow:
1. Откройте терминал и перейдите в директорию `mlflow`:
   ```bash
   cd mlflow


     Запустите скрипт:
    bash

    sh start_mlflow.sh

    После запуска интерфейс MLflow будет доступен в браузере по адресу: http://127.0.0.1:5000

Выводы по ЛР2

    Feature Extraction (полиномы и бины) дал слабый прирост качества. Это ожидаемо для RandomForest, так как деревья решений способны самостоятельно улавливать нелинейные зависимости.

    MLflow обеспечил полную воспроизводимость экспериментов: все параметры, метрики, модели и артефакты зафиксированы. Итоговая модель готова к использованию в ЛР3.
